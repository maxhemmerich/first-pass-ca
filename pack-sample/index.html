What the sample leaves out — and why

It is a real page, not a highlight reel of the best ones. Cutting it any earlier would have given away the wrong thing.

  • No counted table. The page carries no ranked frequencies and no proportional bars; that measured material already exists, free, in the Screen Report.
  • No keyword map. The term-by-term placement work is not on this page.
  • No scripts. The pay and negotiation language stays in the file.
  • No account, no email. The PDF below downloads directly from this site; nothing is captured, and there is no form to fill in.

The honest part: one free page is enough to judge how the file is written and how specific it is. It is not enough to read the pack, and it is not meant to be. If a single page covered it, the rest would not be worth $24 CAD.
